# Technical notes — reproducible methodology

## Source
UCI Online Shoppers Purchasing Intention Dataset (Sakar & Kastro, 2018), DOI 10.24432/C5F88Q, CC BY 4.0. The CSV in this repository is a normalized text representation. Packaged SHA-256: `a7e2714f884a221e95822830fe8e4400e9365d5e5af7c619f3fc6c9343254ad6`.

## Data integrity
12,330 sessions; 18 original columns; 1,908 positive outcomes (15.47%). 125 identical predictor vectors were found with no conflicting target labels. Rows were retained and identical predictor fingerprints were grouped to prevent cross-partition sharing.

## Partition
StratifiedGroupKFold-based 7-fold assignment produced train 8,807 (71.43%), validation 1,762 (14.29%), test 1,761 (14.28%). A grouped three-fold CV ran within training only.

## Pipeline
All fitted preprocessing stays inside sklearn Pipelines. Numeric fields are handled as numeric inputs, categorical features with OneHotEncoder, and the linear-model pipeline includes scaling. No target-derived encoding or SMOTE was used.

## Model selection
Logistic Regression variants and Random Forest variants were compared on validation Average Precision. The selected model is RF with 160 estimators and min_samples_leaf=5. An engineered AvgProductSeconds candidate decreased validation AP from 0.3801 to 0.3778 and was rejected. PageValues was analyzed only as a sensitivity comparison (validation AP around 0.7233) and excluded from the headline model because of unclear timing and outcome proximity.

## Threshold and frozen evaluation
Validation F1 selected threshold 0.25 before any final test evaluation.

Test confusion counts: TN 1250, FP 239, FN 141, TP 131.

## Explanation
Permutation importance was measured on validation, not on the final test. The strongest original features by validation AP drop were Month, ProductRelated_Duration, ExitRates and VisitorType. This is predictive association, not causality.

## Environment and Colab
The original local execution used Python 3.13.5, pandas 2.2.3, scikit-learn 1.8.0, numpy 2.3.5. The user-executed Google Colab run used Python 3.13.16, pandas 2.2.3, scikit-learn 1.8.0, numpy 2.1.3 and reproduced the split and results. scikit-learn 1.6.1 produced different split and test metrics before the version was aligned.

## Files
The executed notebook contains the complete experimental code, plots and saved model generation. Binary model artifacts are generated by the notebook and are intentionally not committed to GitHub. CSV summaries and vector plots document the verified outcomes.
