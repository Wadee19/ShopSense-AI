# GitHub notes

This repository holds my complete notebook, public attributed data, readable documentation, charts and recorded metrics.

## Work with the code
1. Clone the repository or download its ZIP from GitHub.
2. Open `notebooks/shopsense_ai.ipynb` in Google Colab.
3. Run the setup cell and restart the runtime if requested.
4. Run all notebook cells in order.
5. Save your updated notebook and record any new validation experiments before changing the final model.

## Important
Do not add passwords, Kaggle tokens, `.env` files or personal data. A model binary may be regenerated with the notebook; it is not needed in Git history.
