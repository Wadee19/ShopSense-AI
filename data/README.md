# Dataset and attribution

**Name:** Online Shoppers Purchasing Intention Dataset

**Source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset)

**DOI:** https://doi.org/10.24432/C5F88Q

**Authors:** Sakar & Kastro (2018). **License:** CC BY 4.0.

**Kaggle mirror:** https://www.kaggle.com/datasets/imakash3011/online-shoppers-purchasing-intention-dataset

The project uses the original UCI-derived data, 12,330 sessions with the binary `Revenue` target. The packaged CSV uses a normalized encoding/newline representation, so its bytes may not match the HTTP download exactly. The repository file has the same packaged checksum used for the verified runs.

**Expected SHA-256:** `a7e2714f884a221e95822830fe8e4400e9365d5e5af7c619f3fc6c9343254ad6`.

Do not use `PageValues` in the main predictor. The notebook includes it only in a clearly separated sensitivity experiment.
